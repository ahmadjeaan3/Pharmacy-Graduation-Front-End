# مرجع التصميم السابق

هذا المجلد أرشيف للنسخة القديمة والأصول التي استُخدمت كمرجع بصري أثناء بناء الواجهة النهائية.

- `legacy-source`: صفحات ومكونات النسخة السابقة.
- `legacy-public`: الصور والأيقونات القديمة غير المستخدمة في نسخة الإنتاج الحالية.

لا يستورد التطبيق أي ملف من هذا المجلد، ولا ينبغي إضافة ميزات جديدة داخله. عند الحاجة إلى أصل قديم، انسخ الأصل المطلوب فقط إلى `public/assets/app` باسم واضح ثم استخدمه من الميزة المناسبة.
