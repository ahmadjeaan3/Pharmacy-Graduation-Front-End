# حياة دوائية — Frontend

واجهة منصة حياة دوائية المبنية باستخدام React وVite، وتخدم أربعة أدوار: المستخدم، الصيدلية، المنظمة، والإدارة.

## التشغيل

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

عنوان الخادم يحدد في `VITE_API_BASE_URL`. لا توضع مفاتيح JWT أو Google Places أو أي أسرار داخل ملفات Vite.

## أوامر الجودة

```powershell
npm run lint          # فحص JavaScript وReact
npm run format:check  # التحقق من تنسيق الملفات
npm run build         # بناء نسخة الإنتاج
npm run check         # تشغيل الفحوص الثلاثة بالتتابع
```

## أين أجد كل شيء؟

- `src/app`: تشغيل التطبيق، المزودات، والمسارات.
- `src/features`: وظائف النظام مقسمة حسب المجال.
- `src/shared`: الكود العام الذي تستخدمه أكثر من ميزة.
- `public/assets/app`: الصور المستخدمة فعليًا في النسخة الحالية.
- `design-reference`: التصميم السابق وأصوله للرجوع فقط، ولا يدخلان في التطبيق.
- `ARCHITECTURE.md`: شرح كامل لقواعد الهيكل وإضافة أي ميزة جديدة.

## الاتصال بالـBackend

كل ميزة تضع طلباتها داخل مجلد `api` الخاص بها. عميل HTTP العام موجود في `src/shared/api/client.js` ويتولى إضافة جلسة المستخدم ومعالجة انتهاء تسجيل الدخول.

## ملاحظات التسليم

- يتم تحميل الصفحات الكبيرة عند الحاجة لتقليل حجم التحميل الأولي.
- الصلاحيات محمية في التوجيه، ويظل الخادم صاحب القرار النهائي في السماح بالعملية.
- النصوص والواجهات موجّهة للمستخدم العربي وتستخدم اتجاه RTL.
